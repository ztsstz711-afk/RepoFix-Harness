# V2.5 upstream `last()` gate

## Goal

V2.5 在既有三个真实上游案例之外，增加一个此前未参与 Harness 策略调优的 commit-level 修复。案例来自 `more-itertools` issue #1001：一个可正常迭代的对象如果显式声明 `__reversed__ = None`，旧版 `last()` 会误判它支持反向迭代，最终把非空 iterable 错报为空。

上游证据：

- Issue: https://github.com/more-itertools/more-itertools/issues/1001
- Pull request: https://github.com/more-itertools/more-itertools/pull/1028
- Fix commit: https://github.com/more-itertools/more-itertools/commit/cca32949f12d473fd823e37a5530c30d2faa1332
- Parent commit: https://github.com/more-itertools/more-itertools/commit/c834d6e4a0c4280b7b7750cb0de8dd8acb3d4c2c

The upstream commit changes one implementation guard and adds a focused regression test. `scripts/prepare_upstream_last_v2.5.ps1` downloads both fixed commits, verifies hard-coded archive SHA-256 values, copies only the fix commit's changed test file into the parent workspace, and verifies that `more_itertools/more.py` remains byte-identical to the parent implementation.

## Designated gate

The manifest `evals/upstream-last-v2.5.json` authorizes one trial with at most 12 model requests and 32,000 tokens. The Agent receives the task and failing test evidence, but not the fix commit or reference implementation. A focused pass is insufficient for success: RepoFix independently runs the complete upstream suite after `finish`.

The Agent read the implementation and regression test, attempted one whitespace-mismatched localized patch that the tool rejected safely, corrected the patch, ran the focused test, and finished. The accepted change replaced presence checking with a value-aware `__reversed__` guard, matching the semantics of the official upstream fix while modifying only `more_itertools/more.py`.

## Interpretation

This is a new real upstream case, not an authored fixture or injected source regression. The result demonstrates bounded end-to-end feasibility and recovery from a rejected patch. Because the designated gate contains one trial, it must not be reported as a stable success rate; repeated trials belong in a separate future stability experiment.
