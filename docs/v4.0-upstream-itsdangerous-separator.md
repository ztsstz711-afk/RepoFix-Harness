# V4.0 ItsDangerous unsafe-separator upstream gate

## Upstream bug

V4.0 adds the eighth checksum-qualified real upstream bug family. ItsDangerous `Signer` previously accepted separators that can also occur in a URL-safe Base64 signature, making the signed value ambiguous to split. The upstream fix normalizes the separator to bytes and rejects characters from the URL-safe Base64 alphabet.

## Decision

V4.0 does not add automatic model routing and keeps Flash/non-thinking as the default. The defensible conclusion is narrower: Pro demonstrated one bounded full-suite repair that Flash did not complete under the same identity, but the 0/3 Pro repeat shows that a single selected success is not a stability result. Future routing work needs a larger multi-project repeated matrix and a declared promotion threshold.
