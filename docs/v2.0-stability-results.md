# V2.0 repeated upstream stability gate

## Contract

V2.0 不再用单次成功代表稳定性。`evals/stability-v2.0.json` 固定三个 checksum-qualified 上游 Bug，每个 `repetitions=3`，按 trial round 交错执行，共 9 trials。

- Model: `deepseek-v4-flash`
- Docker network: none
- Focused regression baseline and post-patch feedback
- Independent full upstream pytest acceptance
- 12 requests per trial; 108 suite authorization
- Token admission: 32k / 40k / 68k by case
- Hidden exact changed-file evaluation
- No failed-trial reruns or result selection

## Results

| Case | Success | Scope | Requests total/mean | Tokens total/mean |
|---|---:|---:|---:|---:|
| Negative `sliced()` size | 3/3 | 3/3 | 17 / 5.67 | 50,269 / 16,756.33 |
| Running min/max stability | 1/3 | 1/3 | 23 / 7.67 | 98,211 / 32,737 |
| Tomli dotted key limit | 0/3 | 0/3 | 34 / 11.33 | 193,590 / 64,530 |
| **Aggregate** | **4/9 (44.4%)** | **4/9** | **74 / 8.22** | **342,070 / 38,007.78** |

Estimated aggregate cost: **$0.19253849**. Failure counts: `invalid_model_output=3`, `token_budget_reserve=2`. Total format retries: 31.

All four successful trials had a failing baseline, modified only the expected implementation file, and passed the independent complete upstream suite. Sliced was stable at 3/3. Running stability completed one two-patch repair, while two trials ended on empty model output. Tomli produced a correct patch in the earlier single V1.8 gate, but did not repeat it in any of the three V2.0 trials: one JSON action was truncated inside `new_text`, and two trials reached token reserve after repeated empty responses.

## Interpretation

The Harness behavior is reproducible: source/manifest/model/Docker fingerprints are fixed, every request is accounted for, token ceilings hold, failures are classified, source fixtures remain unchanged, and only independent pytest can create success. The model behavior is not yet reliable on the two more complex trajectories.

The honest V2.0 conclusion is therefore:

> RepoFix-Harness is a complete, testable repository-repair harness with objective verification and bounded execution. With the selected low-cost model, repair reliability ranges from 3/3 on a local boundary bug to 0/3 on the parser resource-limit bug; overall real-upstream success is 4/9 in this small gate.

This is not SWE-bench, does not establish a universal 44.4% success rate, and should not be described as production autonomous repair.
