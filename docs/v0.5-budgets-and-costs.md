# V0.5 Budgets, costs, and failure categories

V0.5 makes model consumption an explicit Harness responsibility instead of leaving it to the caller.

## Responsibilities

- `repofix/budget.py` defines provider-neutral run limits, price-based cost estimation, and provider failure classification.
- `repofix/loop.py` enforces limits before the next model request and always records a final pytest snapshot when a budget stops the run.
- `repofix/provider.py` counts successful requests plus JSON-format and transient retries.
- `repofix/suite.py` aggregates usage, estimated cost, and failure categories across isolated tasks.

## Budget semantics

`0` means unlimited. A response that reaches a limit is still allowed to execute because its API cost has already been incurred; the Harness stops before the next model request. This preserves useful work while preventing another paid call.

Suite tasks may override `max_requests` and `max_tokens`. If omitted, they inherit the environment defaults.

## Cost semantics

Costs are estimates based on configurable USD prices per million input, output, and cached-input tokens. All prices default to zero, so a free-tier Gemini run reports zero until prices are configured. Provider billing remains the source of truth.
