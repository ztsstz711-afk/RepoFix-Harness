# V2.4 generalization gate

## Purpose

V2.3 的 phase/context 改进来自 sliced、running min/max 和 Tomli 三类任务。V2.4 不继续重复这些调参案例，而是检查冻结策略在三个不同 Bug family 上是否退化。

`evals/generalization-v2.4.json` 每案例运行三次并交错执行：

1. h11 v0.16.0 第三方源码上的注入 HTTP/1.1 `Expect: 100-continue` 边界回归；完整 suite 为 78 tests。
2. 项目自建 `src/` package fixture，修复跨模块订单折扣作用域；完整 suite 为 7 tests。
3. 项目自建 config fixture，只有 assertion traceback，修复 `None` override 语义；完整 suite 为 2 tests。

每个 success 都需要 failing baseline、独立完整 pytest 和 expected changed-file 命中。h11 是真实第三方源码但 Bug 为注入回归；另外两个是自建 fixture。
