# V2.6 upstream numeric range gate

## Goal

V2.6 adds a fifth checksum-qualified real upstream repair. In `more-itertools`, reversing an empty `numeric_range` called `_get_by_index(-1)` and raised `IndexError` instead of producing an empty iterator. The official fix changes the implementation and adds a focused regression test in the same commit.

Primary provenance:

- Parent commit: https://github.com/more-itertools/more-itertools/commit/247e15b3a489d5805375c95dfa79486c9bd0eb1b
- Fix commit: https://github.com/more-itertools/more-itertools/commit/edb3346f835ca917efbfda5e2d6664ab952da369
